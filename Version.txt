==============================================================================
1.6.6  (2026-09-26)
==============================================================================
Changed
- First list group title is Major Apps.
- Microsoft 365 Copilot with Word installed and no Copilot app
  is Not Installed. Details name the Office program.
- Notepad and Paint are Activated when Windows text and image
  generation is Allow and no app off switch is stored.
- Notepad and Paint Details keep the short status sentence.
- Notepad policy-off Details name the policy key once.
- Status no longer uses the leftover word App running.
- DeepSeek Details say DeepSeek family, not aggressive match.
- Rescan turns Detected off.
- The window starts maximized.
- After a scan the GPU line waits for the next 2-second tick. Two
  failed reads stop the timer and show GPU: --.
- Grok (xAI) Running is Yes when Grok.exe is open.
- Name and How to disable widths are measured again on each scan.
- Other Apps order is A-Z, including ChatRTX and G-Assist.
- Copilot and Microsoft 365 Copilot Activated means the app is
  installed and not policy-off, not a live chat.
- Copy row includes How to disable.
- Every Log.txt event line has a blank line after it. The header
  field block stays packed.
- Paint mixed-policy Details start with Some Paint AI tools may
  still be on. Status stays Deactivated.
- Windows 7 still uses the shorter list. Model-index budget,
  shortcut folders, and new family rows are Windows 10/11 only.
- Detected also keeps Scanner Error rows.
- ComfyUI Installed no longer uses a stable-diffusion-webui folder.
- LM Studio Installed also looks in %LOCALAPPDATA%\LM-Studio.
- Windows On-Device AI with packages or folders and no consent key
  is Installed. Allowed stays Activated. Deny stays Deactivated.
  Details list the consent key when one is found.
- Model index: 8 seconds for the whole walk, depth 4, 20,000 files.
  Skips shortcut folders. Errors log the short folder name, not
  the full path.
- Browser settings files are read up to 4 MB. The text is dropped
  after the AI keys are checked.
- Local Models sit under their own header. Titles use Family
  versions (Vendor). Leftover files are Other Local Models.
- Major Apps titles use Product (Vendor): ChatGPT (OpenAI),
  Claude (Anthropic), Gemini (Google), Grok (xAI),
  Copilot (Microsoft), Ollama, Perplexity.
- Other Apps titles drop Local LLM / GUI tags. NVIDIA rows are
  ChatRTX (NVIDIA) and G-Assist (NVIDIA). Claude Code is
  Claude Code (Anthropic).
- Microsoft Apps titles: Foundry Local, GitHub Copilot,
  Microsoft 365 Copilot, Notepad + AI, Paint + AI,
  Windows On-Device AI.
- Ollama loaded models and tags come from the local HTTP API only.
  The scan does not run ollama.exe or query /v1/models for Ollama.
- Local Models filename match no longer uses bare kimi, gemma, or
  granite. Versioned names still match.
- Perplexity Comet with no AI setting is Unknown. A Comet folder
  without comet.exe is Not Installed.
- ChatGPT leftover Packages folder without a Store app or exe
  is Not Installed.
- Copilot and Microsoft 365 Copilot Details say app present; no
  policy off (not a live-session check) when Status is Activated.
- Jan, Claude, and Foundry Local Running only count a process whose
  path looks like that product. An unread path is not Running.
  Foundry Local also matches FoundryLocal.exe.
- ComfyUI Running only counts python or ComfyUI.exe whose path
  contains ComfyUI. G-Assist and GitHub Copilot stay process-empty
  (Running stays No).
- Ports 8080, 5000, 5001, and 3000 are queried only if llama-server
  or koboldcpp is running from a matching path. Local HTTP JSON
  over 64 KB or not starting with { or [ is ignored.
- Edge with no readable settings files or policy is Unknown. If
  Sidebar or On-device AI is off, leftover model files stay in
  Details and Status is Deactivated.

Fixed
- Build_Wrapper.bat checks each script by hash (64 characters). It
  no longer reads certutil text.
- Open WebUI is Installed only with an exe, docker-compose file,
  open-webui on PATH, or an Apps entry. A data folder alone is
  leftover.
- Port 4891 is only checked if GPT4All is present (LM Studio still
  allowed). Port 1337 only if Jan.exe is present. Port 3080 stays
  off.
- Firefox reads the profile list and only those folders for
  settings. It does not walk cache trees.
- Cursor Apps-list match is a name starting with Cursor plus
  Anysphere or Cursor.exe. Mouse and Cursor Hero stay excluded.
- A scan crash adds a Scanner Error row.

1.6.5  (2026-09-25)
==============================================================================
Changed
- Check for update restores the previous secure-connection setting
  after the GitHub call.
- Model index does not walk Downloads or Desktop. Those folders are
  only a shallow koboldcpp*.exe hunt. Status bar names the folder
  being scanned (Documents\models, Hugging Face cache, and so on).
- README states that Notepad may load a copied settings file with
  reg.exe when the file scan cannot read the AI switch.
- GPU numbers update about every 2 seconds while the window is idle.
  They pause during a scan, then refresh once when the scan ends.
- Scan setup is inside the same try as the scan, so a failure before
  the Windows app list still turns Scan back on and clears the GPU
  pause.
- Summary counts match row colors. Red is running and AI on.
  Blue is AI on with the process closed. Green includes an open
  app whose AI is off.
- Detected hides gray rows only. An open browser with No AI
  Features stays hidden.
- How to disable also appears for Installed and Unknown when
  Installed is Yes. It stays blank for Deactivated and No AI
  Features.

Fixed
- Cancel with no rows: status is Scan canceled, progress is 0,
  Detected and Export stay hidden. That includes cancel during
  startup, the Windows app list, model check, or model index.
  Those paths do not flash Checking for on-device models or
  Indexed N model names, and they do not run ollama list.
- Cancel after some rows keeps the color counts. It does not say
  Scan complete.
- Cancel is checked between index folders, after each folder
  listing, between scanners, and on llama.cpp / KoboldCPP walks.
  Section headers are added after that check so cancel does not
  leave an empty section. A late click after the scan is done
  stays ignored.
- Windows 7 cancel uses the same no-row rule and turns Scan back
  on. It does not say Scan done. Cancel is written to the log.
- Cancel during the Windows app list no longer leaves Scan disabled.
  Buttons are always reset at the end.
- Microsoft Edge + Copilot Installed is Yes when msedge.exe exists.
  Status stays Activated, Deactivated, or No AI Features.
- Claude leftover folders without Claude.exe are Not Installed.
- ChatGPT leftover .codex folder without an exe is Not Installed.
- Broken app-list name match after a regex escape was removed.
  Name match is a simple wildcard only.
- Update check closes the GitHub reply when finished.
- Local port check closes the socket on timeout.
- When started from the exe, the script no longer overwrites the
  exe Log.txt header.
- GPU timer stops when the window closes.
- A scanner error row follows Detected while the scan is running.

Added

  leftover. pip and py are not used.
