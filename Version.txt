Portable AI Scanner
Version history
Format: MAJOR.MINOR.PATCH

How to use this file
- Current app version is shown in the window title and footer (vMAJOR.MINOR.PATCH).
- Update $script:AppVersion in AI_Scanner.ps1 and add a section here for every release.
- Keep newest version at the top.

1.0.0  (2026-08-18)
==============================================================================
Baseline portable Windows 10/11 scanner (no installer).
Run: Run_AI_Scanner.bat or
powershell -ExecutionPolicy Bypass -File AI_Scanner.ps1

Features
- Shows Windows version in the UI.
- Scan button with ListView columns:
  AI Name, Installed, Running, Activated / Status, Version, Details,
  How to disable.
- Colors: Green = Installed, Blue = Activated, Red = Running in memory,
  Gray = Not installed.
- Running = Yes only when an on-device model is loaded in memory
  (not browsers or idle host apps).
- error_log.txt overwritten on each run / each Scan click.
- Window can be maximized.

Major brands
- ChatGPT, Claude, Grok, Ollama, Microsoft Copilot, Perplexity

Local model families
- DeepSeek, Gemma / MedGemma, GLM, gpt-oss, Llama, Mistral / Mixtral /
  Devstral, Muse Glimmer, Nemotron, Phi, Qwen

Browsers
- Brave Leo, Google Gemini (in Chrome), Microsoft Edge Copilot,
  Firefox optional AI, Opera Aria, Perplexity Comet

Other apps / runtimes
- AnythingLLM, ComfyUI / SD WebUI, Cursor, GitHub Copilot,
  GPT4All, Jan, KoboldCPP, llama.cpp / llama-server, LM Studio,
  Msty, Open WebUI, text-generation-webui, vLLM,
  Windows On-Device AI components

Earlier iteration notes included in this baseline
- Individual family detection (aggressive DeepSeek).
- Chrome On-device AI uses Local State
  on_device_ai_user_settings_enabled (not flags-only).
- Firefox prefs.js / user.js AI Controls and browser.ml prefs.
- Uniform browser disable text (settings only).
- How-to-disable column.
- Parser-safe ASCII-only script (no smart dashes).
- Default status is "Not installed" / "No ..." rather than "Unknown".
