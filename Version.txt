Portable AI Scanner
Version history
Format: MAJOR.MINOR.PATCH

How to use this file
- Current app version is shown in the window title and footer (vMAJOR.MINOR.PATCH).
- Update $script:AppVersion in AI_Scanner.ps1 and add a section here for every release.
- Keep newest version at the top.

==============================================================================
1.5.8  (2026-09-20)
==============================================================================
Added
- Status Unknown (Green) when a browser has AI but the on/off setting
  cannot be read (Firefox prefs, Opera Aria, Brave Leo).

Changed
- Detected treats Unknown like other non-gray rows.
- Foundry Local leftover data folder without exe or Apps entry is not Installed.
- Name and How to Disable column widths are saved after the first scan.
  Rescan keeps those widths.
- Status bar shows Indexed N model names (M GGUF files) after the folder walk.

==============================================================================
1.5.7  (2026-09-20)
==============================================================================
Changed
- One process snapshot at scan start. Running checks reuse that list.
- Appx package list is loaded once per scan.
- Local model GGUF count reuses the model-folder index. Those folders
  are not walked a second time.

Removed
- Dev-only launchers Run_AI_Scanner.bat and Run_AI_Scanner.vbs were
  never in a public ship set. Use PortableAIScanner.exe or right-click
  the .ps1 > Run with PowerShell.

1.5.6  (2026-09-20)
==============================================================================
Added
- Official Gemini desktop detection via Google Update GUID
  {533DD80C-942A-4464-B6A9-2E59428D784E} and %LOCALAPPDATA%\Google\Gemini.
- Cherry Studio uninstall registry as a second install signal.

Changed

  process path contains \Google\Gemini\.

- Edge with AI on in settings and no weights.bin is Activated, not off.

1.5.3  (2026-09-19)
==============================================================================
Added
- Firefox 130-132 Labs AI chatbot detection via browser.ml.chat.enabled.
- Firefox 148+ treats AI Controls "available"/"enabled" and a set chatbot
  provider as on. Block AI left off is no longer called optional AI off.

Changed
- First Firefox AI version is 130, not 133.
- How to disable text follows the Firefox version: Labs / General Tabs
  (130-135), General Browsing (136-147), AI Controls (148+).
- How to disable shows only when Installed is Yes. Edge no longer keeps
  that column filled when Copilot is off.
- Running the .ps1 from an already-open PowerShell window no longer hides or
  closes that window. Explorer parent alone is not treated as a one-shot host.
- Browser scan comments are notes only. They do not run. They list what
  to re-check when a new browser version ships: first AI version, Settings
  path to turn it off, pref or policy names, and whether the default is on.
  Each browser function also has a one-line cutoff (Chrome 126, Edge 112,
  Opera 100, Brave 1.52, Firefox 130 / 148).

1.5.2  (2026-09-15)
==============================================================================
Added
- Single-instance check. A second launch asks you to close the open window first.
- Cancel button. It appears only while a scan is running.
- Scan button becomes Rescan after the first scan finishes.

Changed
- Scan button text is Scan.
- Color legend at the bottom of the window is removed.
- Export list is at the top and stays hidden until a scan finishes.
- Detected stays hidden until a scan finishes.
- PowerShell exits when the window closes so powershell.exe does not stay open.
- Cancel is also checked during the pre-scan memory and model-index steps.
- The wrapper holds a mutex and waits until PowerShell exits so a second
  double-click does not start another copy.
- Windows 7 legacy window uses Scan / Rescan / Cancel and has no color footer.
- If you start the script from an already-open command prompt, that prompt
  stays open. Hide and Exit(0) run only for the exe or a double-click from Explorer.
- Unknown parent processes keep the prompt (VS Code and other terminals).
- Wrapper and both scripts use the same mutex name Local\PortableAIScanner.
- Windows 7 also has Detected and Export list with the same hide rules and CSV.
- Wrapper no longer redirects PowerShell output. It only waits until the
  window closes. Rebuild the exe.
- Detected and Export list button positions are swapped (Detected first).
- Cancel stays visible after the first scan and is grayed out when no scan is running.
- Cancel stays visible after the first scan and is grayed out until Rescan.
- Firefox version is read at scan time. Versions with AI but no Settings AI
  Controls page (about 130-147) are called out, with sidebar and update steps.

1.5.0  (2026-09-15)
==============================================================================
Added
- Export list button (bottom right) saves visible rows as CSV for Excel and LibreOffice.

- GPT-J / Pygmalion model-file row.

- Foundry WinGet search looks only two folders deep for foundry.exe.

- Edge checks OptGuideOnDeviceModel\weights.bin the same way Chrome does.
- Edge Activated only if a large weights.bin is on disk and On-device AI is not off.

- Log.txt header is "Portable AI Scanner Log" and includes version and Windows.

Fixed
- Detected filter no longer throws on -ListView.
- One CSV export path. The unused tab-separated writer is gone.
- Foundry no longer stores a wildcard path as the executable.
- Scan-LocalModels was missing a closing brace and blocked the wrapper from starting.
- Window controls are created before the form is shown.
- Model name index is built once per scan. An empty index no longer
  logs "Model name index size: 0" for every family.
