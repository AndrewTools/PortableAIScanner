Portable AI Scanner
Version history
Format: MAJOR.MINOR.PATCH

How to use this file
- Current app version is shown in the window title (vMAJOR.MINOR.PATCH).
- Update $script:AppVersion in AI_Scanner.ps1 and add a section here
  for every release.
- Keep newest version at the top.

==============================================================================
1.6.0  (2026-09-20)
==============================================================================
Added
- Check for update button on the title row.

Changed
- Firefox 141-148 disable paths and browser.ml.linkPreview.optin.
- Firefox 147 tab-group AI uses Settings > General > Tabs > Interaction.
- Firefox 148 Block AI does not cover pageAssist, smartAssist, or
  browser.ml.enable. If those are on, Status is Activated and Details
  lists them.
- Splash stays up at least 700 ms so Loading is readable on a fast start.
- Wrapper picks Windows 10/11 from ProductName or build 10240+, not
  CurrentVersion 6.1 first.
- Model index uses depth 4, a file cap, and an 8 second budget per root.
- List fill no longer jumps to every new row.
- Local port probe always closes the socket.
- Load trap exits if the window was not created.
- Check for update only opens this project's GitHub release pages.
- llama.cpp search under Downloads and Desktop is two folders deep.
- Some desktop hosts treat a leftover data folder as Not Installed.
- Model index skips browser weights.bin outside OptGuide folders.
- Notepad and Paint with no stored AI toggle are Unknown.
- Scan-complete bar uses Green / Blue / Red.
- Log.txt no longer writes User and Computer.
- Windows 7: no unused download helper, open port is not Running,
  model index is GGUF/safetensors only with depth 4 / 20,000 / 8 s,
  no Internet Explorer row.

Fixed
- Unused FindWindow import removed from the wrapper.
- Appx name matching escapes dots before wildcards.
- Check for update uses one repo setting for the API and the allow-list.
- Chrome Gemini version parse uses one variable.
- Unused Aggressive switch removed from the model-family search.
- Already-running script exits 2 so the wrapper log matches.

1.5.9  (2026-09-20)
==============================================================================
Added
- Firefox leftover profile folder is named in Details when firefox.exe
  is gone. Status stays Not Installed.
- Firefox Details list Labs chatbot, General > Tabs AI, and link
  previews separately.

Changed
- Firefox How to disable names only the feature that is on. Labs and
  General > Tabs are not treated as the same setting.
- Firefox 147 treats General > Browsing > Enable link previews as its
  own item, not mixed into Labs.
- Firefox 136-147 keeps the link-preview disable path when that setting
  is on or unknown.
- Microsoft Copilot Installed is only the Settings > Apps Copilot
  package (Microsoft.Copilot*). Leftover ms-copilot protocol or
  WindowsCopilot class is Details only.
- ChatGPT Appx match is OpenAI.ChatGPT* / OpenAI.Codex* only.
- Notepad AI Appx match is Microsoft.WindowsNotepad* only.
- Claude desktop Appx match requires Anthropic in the name or publisher.
- Cherry Studio, LM Studio, and GPT4All leftover data folders without
  an exe are Not Installed.
- Microsoft Copilot and Microsoft 365 Copilot are Activated (Blue) when
  the app is present and not turned off by policy.
- Microsoft 365 Copilot uses Office Enable Copilot / TurnOffCallout
  when found; otherwise Installed.
- Notepad settings.dat also reads WritingToolsEnabled. Text and image
  generation Deny or LetAppsAccessSystemAIModels=2 marks Notepad, Paint,
  and Windows On-Device AI as Deactivated. Installed stays Yes.
- Notepad, Paint, and Windows On-Device AI are Activated (Blue) when
  the AI switch is on. Deactivated stays Green.
- Status bar shows Loading Appx packages before Get-AppxPackage.
- Exe shows a splash until the main window is ready.
